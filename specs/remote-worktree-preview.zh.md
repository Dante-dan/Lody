# 会话级远程 worktree 预览

Status: draft
Translation: current

[English](remote-worktree-preview.md)

用户查看另一台机器上的会话，点击指向同仓库另一 worktree 的绝对文件链接时，预览应显示该 worktree 的真实文件，不重定向到会话工作区。用户必须先在拥有会话的机器上授权这个具体根目录。本草案提出新的授权边界；当前远程预览尚未实现它。本修订没有人工批准，也不声称已扩大运行时访问权限。

## 职责

拥有会话的机器通过可信授权界面展示会话所有者、规范根路径及只读范围，随后由用户明确确认。Agent 输出、Markdown 链接、shell 工作目录变化和 Git 仓库归属不能签发授权；远端查看者不能自行取得任意主机访问权限。

Daemon 负责授权存储和校验。每项授权绑定一个已有权限的会话所有者、一个规范 worktree 根，以及随 worktree 移除或替换而变化的生命周期标识。明确授权后再检查仓库关联，关联本身不足以授予权限。授权不扩展到所有会话、整个仓库或所有相邻 worktree。

预览服务每次读取都检查当前会话权限及当前授权，解析符号链接后验证目标位于授权根内。授权仅为绑定的会话补充现有预览边界。现有工作区、临时目录、聊天目录及运维配置的额外根保留原有语义；daemon 级环境允许列表不是会话级授权。

查看界面保留解析后的绝对目标和分支对应文件身份。获准的外部文件仍只读，不授予 Code Collab 激活、保存、shell 执行或在查看者机器上打开远程路径的权限。现有响应大小与二进制限制仍适用。

## 生命周期与协议要求

创建授权必须由会话的合法所有者在主机侧明确批准。没有匹配有效授权的读取遵循当前拒绝行为。会话重新归属使原所有者授权失效。撤销或根目录移除阻止后续读取；若解析或读取期间发生撤销，必须在返回内容前重查权限。已经显示的内容无法收回，界面不得暗示可以收回。

同一路径上的 worktree 被替换后，原授权不得继续有效。无法确定生命周期身份时拒绝访问。若选择持久授权，daemon 重启后必须先重新验证所有者及生命周期；旧缓存不能恢复权限。不支持该能力的客户端或 daemon 保留现有预览行为，不回退到 Electron 同机任意文件读取能力。

存储表示、生命周期身份证明、经过身份验证的主机确认、协议协商及撤销传播仍待人工设计评审。本草案规定它们必须实现的结果，不定义线格式、接口名或已完成的实现。托管后端与私有记录不属于本公开 Spec。实施拟议权限或协议变更前，批准必须链接到本草案的确切修订。

以下是后续实现的计划检查，不是本次文档修改已执行的运行时测试。扩展现有负责该边界的测试套件。

| 验收边界          | 可观察场景与计划验证                                                                                                               |
| ----------------- | ---------------------------------------------------------------------------------------------------------------------------------- |
| worktree 身份正确 | 在路径策略/服务套件中为根 A 的会话授权根 B；预览 B 的文件并核对内容和规范路径，不改变 A 内同名文件。远程界面 QA 核对分支文件身份。 |
| 会话与所有者隔离  | Daemon 授权/handler 测试拒绝未授权的另一会话、不同所有者及重新归属后的会话，即使属于同仓库。                                       |
| 规范路径包含      | 路径策略测试拒绝相邻根、父路径越界及逃出授权根的符号链接；缺失路径错误不能成为存在性探测。保留现有大小写与歧义规则。               |
| 撤销与替换        | 用确定性的授权状态变化验证撤销、移除、替换后读取失败，读取期间撤销在响应前阻止内容；重启不能恢复失效授权。                         |
| 只读边界          | 服务/客户端测试保留 external/readonly 结果及原保存拒绝；界面 QA 确认预览不激活 Code Collab 或查看者机器系统操作。                  |
| 兼容与限制        | 无协议协商的现有调用仍受原限制；服务测试保留有界完整远程响应及原超限拒绝。                                                         |

## 有界主机适配器（Electron 管理的根会话）

生产预览服务已接入注册表，但在明确主机确认前没有授权。本地专用 `file/grant-worktree` 仅接收会话与目录，不接收批准、用户身份或授权代次。会话必须是本机 daemon 用户所有、未归档或删除的根会话；目录必须共享规范化 Git common directory，且是登记的准确 worktree。本切片不支持子会话。

只有实际管理该 CLI 子进程的 Electron 可批准：daemon 通过继承的私有 Node IPC 发出新挑战，Electron 主进程原生对话框显示会话、所有者和规范目录，默认取消。结果必须在 30 秒内由同一私有通道返回，并匹配挑战。重放、过期、并发和断连均拒绝；确认后重核授权代次与目录身份。supervisor 能力仅留在主进程/worker 内存，不落盘、不记日志、不交给 renderer。独立 daemon 或附着到既有 runtime 的 Electron 缺少该通道，拒绝授权。

归档、删除、用户/机器/父会话/项目元数据变化及本地 `file/revoke-worktree` 推进 daemon 自有代次并撤销访问；重启为空。既有远端 `file/preview` 仍有界只读，不增加远端授权 RPC、保存能力或 Code Collab 激活。本地请求者可请求原生确认，不能直接批准。当前是适配器/API 切片，没有新增远端 viewer 授权按钮。未进行原生桌面 UI 或跨机器端到端 QA；draft 不表示已批准意图，也不表示所有 #472 部署均已支持。
