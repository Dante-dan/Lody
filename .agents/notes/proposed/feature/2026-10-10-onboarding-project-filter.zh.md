# 在本地筛选已有引导项目

Status: proposed
Translation: current

[English](2026-10-10-onboarding-project-filter.md)

## 摘要

Issue #1386 报告需要滚动 186 个已连接仓库。现有视图合并本地与 GitHub 项目，并选择一个项目。参考改动在本地筛选现有列表，让选择独立于筛选，并提供键盘操作。方案仍待上游评审，不代表人工批准。

## 决策与取舍

使用一个始终显示的输入框处理两类项目，而不是只筛选仓库或依数量阈值显示：本地桌面用户也需要查找，加载过程中控件行为应稳定。匹配名称、稳定标识和已显示详情，不新增云请求或遥测内容。保留单选，因为当前完成接口只接受一个项目；请求中假定的多选并非当前行为。

项目行使用原生按钮，方向键移动焦点、Enter 激活、Escape 重置。移除退出动画，让筛掉的行立即离开键盘目标集合。筛选不丢弃隐藏的已选项目。

## 范围与验证

对应[草案 Spec](../../../../specs/onboarding-project-filter.zh.md)。扩展已有引导流程测试和长列表 Storybook 状态，不另建测试工具。覆盖所有者匹配、可见性、本地名称、空结果、键盘焦点与选择、清除后保留选择。真实执行结果记录在贡献说明；代码分析和测试不等于桌面实机认证。
