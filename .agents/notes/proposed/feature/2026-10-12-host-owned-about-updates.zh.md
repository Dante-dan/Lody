# 主机负责的关于页更新

Status: proposed
Translation: current

[English](2026-10-12-host-owned-about-updates.md)

## 摘要

APK 用户目前需要离开应用寻找官方更新。新增可选的公共主机端口，让共享关于页展示更新状态并执行用户动作，版本查询、下载及安装仍由主机负责。同一端口用于窄与宽关于页的版本行，现有 Electron IPC 保持原行为。这是 #1486 的参考实现，不包含 Android 下载器，也不代表原生端已经接入。

## 决策与证据

采用现有应用图标选择的挂载前可选主机能力模式，快照使用 platform 的 `ReadonlyStore`。没有能力时隐藏控件；挂载只订阅，不检查更新或轮询。主机选择下载、安装、打开官方更新页、重试动作，共享 UI 不接收文件路径或版本下载 URL。命令拒绝时展示通用可重试错误，并保留失败动作供用户重试。

这是普通共享功能与实现边界，没有新增需要 Spec 审核的安全、归属、持久性或兼容保证。不标记 Spec 批准，不声称人工审核。[应用图标决策](../../implemented/feature/2026-09-20-app-icon-selection.zh.md) 提供相邻的主机能力先例。

窄与宽布局的六项合成 React 测试已通过，覆盖动态版本/状态、用户命令、能力缺失、进度与失败重试。platform 合同类型检查已通过；Storybook 覆盖有意义的快照状态。APK 原生查询、下载、安装及真机验证仍属于外部主机仓库。完整检查及实际结果保存在交付证据中，不由本提案推断。
